# ERLAB 登場人物と演出メモ

## 指導役

**三嶋 かなえ**（33）中央検査部主任。ER担当が長い。

- 早口でざっくばらん。
- 褒めるときは短く「ん、いいね」。
- 危ないときだけ声が一段低くなる。

**羽鳥 悠介**（29）かなえの2年後輩だが指導は丁寧。

- 教科書的な言い方を崩さない。
- 焦らせない代わりに逃げ道も作らない。
- 感情を表に出さない。

## 立ち絵の使い分け（`assets/portraits/`）

| 表情 | 使う場面 |
|---|---|
| `normal` | 通常のナビ |
| `serious` | 緊急報告を指示する場面（症例4など） |
| `alert` | 強く制止する場面（症例5-bの「待って」） |
| `praise` | 良い判断をしたとき（症例5で溶血に気づく） |
| `deadpan` | かなえ：呆れ（要改善のとき） |
| `troubled` | 悠介：言いにくいことを伝えるとき（`deadpan`に対応） |

立ち絵は明るい地色（`#eceae4` / `#fff`）で使う前提。
濃色背景に置くと髪の隙間に明るい縁が出る（元絵側の塗りが原因）。

## 絵柄の方針

アニメ寄り、低彩度、細い線。写実にしない（実在の医療従事者に見えるのを避ける）。

**患者の立ち絵は作らない。** 検査技師は患者の顔を見ないため、顔があると数字ではなく
印象で判断する癖がつく。患者は依頼票の情報のみ。

## ナビの段階設計

| 段階 | ナビの出し方 |
|---|---|
| 症例1〜3 | 全部説明する。操作と用語を覚える段階 |
| 症例4〜6 | 見どころは示すが結論は言わない。報告後に解説が届く |
| それ以降 | ナビは一行のみ。詳細は索引を自分で引く |
| 上級 | ナビと索引を外す。指導役が不在の日として物語化する |
