# ERLAB 登場人物と演出メモ

## 指導役

**三嶋 かなえ**（33）中央検査部主任。ER担当が長い。

- 早口でざっくばらん。
- 褒めるときは短く「ん、いいね」。
- 危ないときだけ声が一段低くなる。

**羽鳥 悠介**（29）かなえの2年後輩だが指導は丁寧。

- 教科書的な言い方を崩さない。
- 焦らせない代わりに逃げ道も作らない。
- 感情を表に出さない。

## 立ち絵の使い分け（`assets/portraits/`）

| 表情 | 使う場面 |
|---|---|
| `normal` | 通常のナビ |
| `serious` | 緊急報告を指示する場面（症例4など） |
| `alert` | 強く制止する場面（症例5-bの「待って」、症例4の割り込み） |
| `praise` | 良い判断をしたとき（症例5で溶血に気づく） |
| `deadpan` | かなえ：呆れ（要改善のとき。症例7で報告レベルを下げたときなど） |
| `troubled` | 悠介：言いにくいことを伝えるとき（`deadpan`に対応） |

立ち絵は明るい地色（`#eceae4` / `#fff`）で使う前提。
濃色背景に置くと髪の隙間に明るい縁が出る（元絵側の塗りが原因）。

**絵の幅は描き直しで変わる**（いまは306〜310px。高さは1232pxでそろえる）。
画面では**高さ**で大きさを決め、幅は絵なりにする。幅や縦横比を決め打ちすると、
描き直したときに崩れる。

## 絵柄の方針

アニメ寄り、低彩度、細い線。写実にしない（実在の医療従事者に見えるのを避ける）。

**患者の立ち絵は作らない。** 検査技師は患者の顔を見ないため、顔があると数字ではなく
印象で判断する癖がつく。患者は依頼票の情報のみ。

## ナビの段階設計

| 段階 | ナビの出し方 |
|---|---|
| 症例1〜3 | 全部説明する。操作と用語を覚える段階 |
| 症例4〜6 | 見どころは示すが結論は言わない。報告後に解説が届く |
| それ以降 | ナビは一行のみ。詳細は索引を自分で引く（症例7が最初の一行ナビ） |
| 上級 | ナビと索引の「項目」を外す。指導役が不在の日として物語化する。
       「言葉」の辞典と「見る順番」は残す（調べるのが常に損にならない設計） |

## 症例0（実装済み）

検査値を一切出さないチュートリアル。配属初日、指導役が画面の見方だけを説明する。全9ステップ。

- 受付一覧
- 結果画面の各列
- フラグ記号
- 検体状態欄
- 項目名タップで索引が開くこと
- マーク（行をタップして反転）と疑いタブ
- メッセージ欄

報告の三段階にも触れるが、この時点では通常報告しか使わせない。
疑いタブは「最初は選ばなくていい」と言い添える。空欄でも報告できる。

## 差し戻し（症例7）

一本目を報告すると、医師の返信が**差し戻し**で返って症例が閉じない。指導役が一言（normal）挟み、
数秒後に二本目が届いてから、もう一度報告する。教えたい判断は二本目にあるので、一本目の枝には
講評を付けない。

最終評価は min（二本目の評価、一本目の `cap`）。一本目でパニック値を至急に落としたり、
緊急報告に項目を並べすぎたりすると、二本目を完璧にやっても許容までしか戻らない。

医師は悪者にしない。見込み違いを認めて対応する人として書く。

## 割り込み（症例3 → 症例4）

症例3を開いてしばらく経つか、症例3を報告する直前にERから至急が入る。
ヘッダーが赤に変わり、受付一覧の先頭に症例4が上がり、指導役が `alert` で一言。
症例4を報告すると白に戻り、症例3が未報告なら申し送りで軽く触れる（評価は下げない）。

新人研修では1回だけ。上級モードでランダム化する（roadmap の進め方 8）。
設定は症例JSON側（`n03.json` の `interrupt`）に持たせてある。

### 決まっていること（変更時は理由を残す）

- 医師パートは作らない。病名は当てさせない
- 溶血などの検体トラブルの数値表は固定。症例側の素の値で調整する
- 基準範囲・パニック値は `hospital.json` の1セットのみ
- 患者の立ち絵は作らない
- 医学教育教材を名乗らない
- **指導役が講評するのは、その症例で教えたい判断に関わる分岐だけ。**
  それ以外の分岐は医師の返信のみで閉じる。分岐を埋めるためだけに台詞を書き足さない
- 報告後は「（あれば）指導役の講評 → 医師の返信」の順で届く。医師の返信は
  `speaker` なしの共通文で、どの分岐にも必ず1本つく
- 自由記述の欄は作らない。隠すのではなく置かない。コメントは候補のタップで組む
- 辞典は一語三行以内で病名を書かない。「見る順番」は全症例で同じ五行、上級でも消さない
- 指さしは一文に一か所。点滅させない。症例4以降には書かない
- 医師の差し戻しはランダムにしない。手書きの症例だけで起こす。
  「医師に反論する」入力欄も作らない。返すのは報告レベルであって言葉ではない
- 二段の症例では、教えたい判断は二本目にある。一本目の枝に講評を付けない
- 操作は「見つける（マーク）→ 疑う（タブ）→ 調べる → 報告する」の四段階。
  「調べる」（検体目視・ID照合・塗抹・依頼元へ電話）は実装済み（docs/investigate.md）
- **指導役に聞ける（`ask`）。** 上のバー右端の「聞く」で、1症例1回。
  位置は症例・モードによらず固定で、ナビ枠が出ていないときも出る。
  指導役はその症例の**見どころ**を言うだけで、答えは言わない。
  聞いた症例の最終評価は許容どまりになる（`cap` を ok に落とす。枝は書き換えない）。
  押す前にもボタンの横で「聞くと許容どまり」と言っておく——隠して減点しない。
  台詞は手書き症例だけ2本ずつ持ち、書いていない症例と生成症例は索引の「見る順番」の
  五行をその指導役の言い方で出す（生成症例に台詞を付けない方針をこれで守る）。
  指導役がいない日（上級モード、症例が `mentor: false` の日）は、押すと
  「今日は指導役がいません。自分で判断してください。」が出るだけで、評価の上限は落とさない
- 電話で返るのは検体側・採血側の事実と、横の連絡として当然の患者の様子まで。
  病名・身体所見・診断の示唆は返さない。塗抹も「見えた形」まで（芽球・異型は読まない）
- 疑いタブに病名は並べない。検体・検査室側の見立てだけ。自由記述欄も作らない
- マーク行の反転と、割り込み中のヘッダーの赤は色ルールの例外。
  前者は選択状態、後者は画面状態の表示で、どちらも値の判定ではない（CLAUDE.md）
- 症例5-bの評価（2026-09-07 決定）。最善は一本にした
  - 緊急報告＋コメント＋再採血：**最善**
  - 至急報告＋コメント＋再採血：許容（HHを至急に落としているため。理由は症例4と同じ）
  - 緊急報告のみ：許容
  - 再採血のみで報告なし：要改善
  - （2026-09-08 追加）最善の条件にKのマークと「採血に問題なし」＋「溶血」の両方を足した。
    溶血だけを選んで再採血で止めると要改善のまま
