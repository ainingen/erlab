# 疑い「本物の異常」の改名と、選ぶ根拠のナビ（2026-09-08）

`docs/comment-list.md` の続き。ブランチ `comment-list` の上に積む。読む順は mechanics.md 2章 → comment-list.md → これ。

## 背景

通しプレイ（症例3）で、作者本人が疑いタブの「本物の異常」を押せなかった。
理由は二つ。

1. **札の言葉が重さに読める。** 慢性のHb 9.4に「本物の異常」を付けるのは心理的に抵抗がある。
   タブが聞いているのは重さではなく「値が患者のものか、採血のせいか」なのに、それが伝わらない
2. **選ぶ根拠が画面のどこにもない。** 症例0で一度説明したきりで、症例1〜3のナビはマークにも疑いにも触れていない

「検体に問題なし」も試したが、「体に異常なし」と読み違える。「検体」は一般語ではない。
動作の言葉「採血」で言い、括弧で値の出どころを補う形に決めた。

## 変えること

### 1. `data/suspects.json` — `real` のラベルとヒント

内部ID `real` は変えない（症例JSONの `choices.when.suspects` と `comment_templates.json` が参照している）。

```json
{
  "id": "real",
  "label": "採血に問題なし（値は患者由来）",
  "hint": "溶血・凝集・希釈・取り違えのどれでもない。この数字は患者の体の状態。重いか軽いかは別の話"
}
```

タブのボタンが長くなる。スマホ縦390pxで二行に折り返してよいが、他の5つと同じ行の高さに揃える
（折り返す札だけ背が高いと、それが目立って重さに見える）。

### 2. `data/comment_templates.json` — `real` の文

```json
{
  "id": "real",
  "text": "{item}：採血に問題なし、値は患者由来と判断",
  "speech": "{item} {value}、採血に問題なく、患者由来の値と判断します"
}
```

### 3. `data/glossary.json` — 語を二つ足す（「言葉」タブ・一語三行の型）

**`suspect`（疑い）** — 疑いタブの見出しの「?」から開く

> 何か：マークした値が「患者のもの」か「採血のせい」かの見立て。重さや新しさは選ばない
> なぜ迷うか：値だけ見ても区別がつかない。採血のせいなら再採血で消え、患者のものなら残る
> 何を見れば分かるか：検体状態欄・関連する項目の動き・前回値との向き。採血側の5つを消していくと、残るのが「採血に問題なし」

**`real`（採血に問題なし）** — 疑いタブの `real` の「?」から開く

> 何か：溶血・凝集・希釈・取り違え・前回値との乖離のどれにも当たらない、という判断
> なぜ選ぶか：この値を患者の値として医師に渡す、という宣言になる。「異常なし」ではなく「値は本当」の意味
> 何を見れば分かるか：検体状態欄が空、関連項目が同じ向きに動いている、前回値と矛盾しない。三つ揃えば選ぶ

疑いタブの「?」はいまタブ全体に一つ。`real` にだけもう一つ付けるのが煩わしければ、
タブの「?」から `suspect` を開き、その本文の「採血に問題なし」を `real` へのリンクにする形でもよい。

## 実装との差

### 札の高さ

`.suspects` を `align-items: stretch` にして、同じ行の札が同じ高さになるようにした
（見出しの「Hb の疑い」と「?」だけは中央に置く）。実際には 390px でも 320px でも
「採血に問題なし（値は患者由来）」は折り返さず、他の5つと同じ 34px に収まっている。
折り返したときの保険として入れてある。

### 報告対象の並びは短いほうを使う

`markSummary()`（報告ダイアログの「報告対象」と判定の一行）は疑いの札をそのまま並べるので、
「Hb（採血に問題なし（値は患者由来））」と括弧が入れ子になった。並べるときだけ**末尾の括弧を落として**
「Hb（採血に問題なし）」にしている。タブの札そのものは仕様どおりの長いまま。

### 辞典の「?」

疑いタブの見出し「Hb の疑い」の**語そのもの**を `suspect` へのリンクにした（仕様の後半の案）。
`real` の「?」は、既存の「疑いのIDが辞典にあれば `?` を出す」仕組みにそのまま乗ったので、
辞典に `real` を足しただけで出るようになっている。どちらも実機で開くことを確認した。

辞典の語は16→18。並び順は「画面を見る順」なので、疑いの群の先頭（`suspect` → `real` → 溶血 …）に置いた。
`readable.md` の語の表にも2行足してある。

### 「本物」の残り

仕様の §6 のとおり `suspects.json` / `comment_templates.json` / `rookie.json` / `tutorial.json` /
`dialogue.md` / `mechanics.md` / `design.md` 3-1 から消した。加えて、プレイヤーに出る文なので
**判定の見出し3本**（症例4「本物かどうかの見立て」、症例5-b の2本、症例7）も言い換えた。
`characters.md` の症例5-bの記録も一行直した。

普通名詞として使っている次の箇所は**残した**。タブの札を指していないため：

- `glossary.json` の溶血「本物の異常と区別がつかない」、駆血「戻らなければ本物」
- `design.md` の「その異常は本物か」「溶血があっても本物のことがある」
- `roadmap.md`・`README.md`・`dialogue.md` の地の文

台詞のうち3か所は、置き換えると文が壊れるので言い換えた（`dialogue.md` も同じに直した）：

| 元 | 直し |
|---|---|
| つまり本物。（症例4・かなえ） | つまり採血に問題なし。値は患者のもの。 |
| その値が本物かどうかを先に決めて（症例5・申し送り） | その値が患者のものかどうかを先に決めて |
| じゃあ本物じゃないの？（症例4・外れの講評） | じゃあ患者の値じゃないの？ |
