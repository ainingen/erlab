# 効果音（Web Audio 合成・2026-09-08）

音声ファイルは置かない。すべて `src/sound.js` で合成する。依存なし。PLiCyの1ファイル結合と相性を取るため。

## 方針

- **音は合図であって情報ではない。** 色ルールと同じ：音を切っても同じ判断ができる状態を保つ
- **値の重さに音を付けない。** HH / LL が出たときに警報を鳴らさない。「HHを見たら電話」の反射を
  作らないという危険域の方針（CLAUDE.md）と同じ理由。鳴るのは**出来事**（結果が届いた・メッセージが来た・
  電話をかけた）だけで、値の中身では鳴らさない
- 短く、小さく、同じ出来事には毎回同じ音。検査室のBGMは作らない（装置の音と通知音しかない部屋）
- 声は付けない（別件。やるなら短い決め台詞だけ）

## 音の一覧

`play(name)` で呼ぶ。合成のパラメータは目安。実装で耳で合わせてよいが、長さの上限は守る。

| name | 出来事 | 音 | 長さ |
|---|---|---|---|
| `result` | 検体を開いて結果が表示された | 装置の電子音。矩形波 1760Hz を 60ms×2（間 60ms） | ≤0.2s |
| `message` | 院内メッセージが届いた（申し送り・講評・医師の返信） | 正弦波 880→1320Hz の二音、各 80ms | ≤0.2s |
| `interrupt` | ERの至急が割り込んだ | 三角波 1320Hz 120ms×3（間 80ms）。`message` より強く、**一回だけ**。点滅と同じで繰り返さない | ≤0.6s |
| `tap` | マーク・疑い・コメント候補のタップ | 正弦波 2000Hz 15ms、音量 0.15 | ≤0.02s |
| `send` | 通常・至急の送信 | 正弦波 660→990Hz 90ms（上がる） | ≤0.1s |
| `dial` | 緊急報告の電話画面を開いた | 呼出音。正弦波 440Hz+480Hz を 1.0s 鳴らして 0.5s 休み。電話画面が閉じるか読み返し確認まで繰り返す（最大3回） | 4.5s まで |
| `pickup` | 読み返し確認をとった | `dial` を止めて、正弦波 990Hz 60ms | ≤0.1s |
| `close` | 症例が閉じた（判定が出た） | 正弦波 990→660Hz 90ms（下がる。`send` の逆） | ≤0.1s |

音量はマスターで 0.3。`tap` だけさらに小さく。エンベロープは全部アタック 5ms・リリース 30ms で
クリックノイズを出さない。

**鳴らさないもの**：フラグ・危険域・Δ・検体状態欄の表示。辞典を開く。指さしの「ここ」。
判定の best / ok / poor（評価に音の差を付けると、音で答えが分かる）。

## 解錠とON/OFF

- スマホは最初のタップまで鳴らせない。**指導役を選ぶタップ**で `AudioContext` を作って resume する。
  それ以前は `play()` を呼んでも黙って捨てる
- ヘッダーに音のON/OFF（`🔊` / `🔇` の文字とラベル「音」。アイコンだけにしない）。
  `localStorage` の `erlab.sound` に保存。既定は **ON**
- OFF のときは `AudioContext` を作らない（`play()` は即 return）
- `prefers-reduced-motion` とは連動させない（音と動きは別の設定）

## 構成

- `src/sound.js` … `init()`（解錠）、`play(name)`、`stop(name)`（`dial` 用）、`isOn()` / `setOn(bool)`。
  DOM に触らない。`AudioContext` が無い環境（テスト・古い端末）では全部 no-op
- `src/app.js` … 出来事の場所で `play()` を呼ぶ。呼ぶ場所は上の表の8か所だけ。
  判定や描画の関数の中では呼ばない（`renderAll` が走るたび鳴るのを防ぐ）
- `index.html` … ヘッダーのON/OFFボタン

## テスト

- `sound.js` を `AudioContext` なしで import して `play()` が例外を出さない
- `setOn(false)` のあと `play()` が何もしない。`localStorage` に保存される
- 音の一覧が8本で、それ以外の name を渡すと no-op（例外にしない）
- `app.js` のコードに、`renderAll` / `renderResults` / `evaluate` の中から `play(` を呼ぶ行がない
  （文字列で検査。値の判定と音を結び付けない）

## 実装順

1. `sound.js` と8本の合成
2. 解錠（指導役の選択）とON/OFF
3. `app.js` の8か所に差す
4. `dial` のループと停止
5. テスト。CLAUDE.md の「守ること」に「音は出来事にだけ付ける。値の重さに付けない」を一行足す

## やらないこと

- 音声ファイル、BGM、声
- HH / LL・危険域・判定結果に音を付けない
- `interrupt` を繰り返さない（点滅と同じ扱い）
- ON/OFF をアイコンだけにしない

## 実装との差

### 同時に起きる出来事は、音だけ少しずらした

通常・至急の報告では「送信」「症例が閉じた」「返信が届いた」が同じ一瞬に起きる。
三つを重ねると上がる音と下がる音が混ざって、何が起きたのか分からなくなるので、
`send`（0ms）→ `close`（150ms）→ `message`（400ms）の順に置いた。
緊急報告も `pickup`（0ms）→ `close`（150ms）。ずらしているのは音だけで、画面は同時のまま。

### `message` を鳴らす場所は2か所

「院内メッセージが届いた」で鳴らすのは、**報告のあとの講評＋医師の返信**（`finishReport`）と、
**差し戻しの二本目が届いたとき**（`deliverFollowup`）だけにした。

- シフト開始の挨拶3本は解錠前（指導役を選ぶタップの中）で届くので、そもそも鳴らせない
- 検体を開いたときの申し送り・ナビは `result` と同じ一瞬なので、`result` だけにした。
  そうしないと検体を開くたびに三つの音が重なる

### `tap` のエンベロープ

15ms の音にリリース30msは長いので、リリースは音の長さで頭打ちにした（アタックも長さの半分まで）。
`tap` は実測で 15ms + リリース15ms の 30ms に収まっていて、仕様の上限（0.02s の本体）は守っている。

### `dial`

3周期ぶん（1.0秒鳴らして0.5秒休み ×3）を最初にまとめて予約し、`stop('dial')` で6本の音源を
まとめて止める。長さは合計4.0秒（最後の休みは数えない）で、仕様の4.5秒以内。
440Hz と 480Hz は同時に鳴るので、それぞれ音量を半分にしてマスターを超えないようにした。
**「電話を切る」でも止める**（仕様の「電話画面が閉じるか読み返し確認まで」）。

### ON / OFF

ヘッダーのボタンは「🔊 音 入」「🔇 音 切」。文字とアイコンの両方を出し、`aria-pressed` も付けた。
OFF のあいだは `AudioContext` を作らず、`play()` は即戻る。ON に戻したときは、その場のタップで
解錠できるので `init()` を呼び直している。

### テスト

テストはブラウザで走るので `AudioContext` 自体はある。仕様の「`AudioContext` なしで import して
例外が出ない」は、**解錠していない状態（`init()` を呼んでいない）で `play()` が何も起こさない**
ことに読み替えた。実際そのおかげでテスト中は一度も音が鳴らない。

- `test/sound.test.js` を追加（5本）。`app.js` のソースは `test/index.html` で `fetch` して渡す
- 「描画・判定の中から `play()` を呼ばない」は、`renderAll` / `renderVerdict` などの関数の中身を
  波括弧の対応で切り出して、`play(` が入っていないことを見る形にした。
  `renderResults` / `evaluate` は `app.js` で定義していない（import しているだけ）ので、
  見つからなければ飛ばす
- 鳴らさないと決めたもの（辞典・指さし・メッセージの描画）の周りでも `play()` を呼んでいないことを見る
- `localStorage` を書き換えるテストは、終わったら元の値に戻す
