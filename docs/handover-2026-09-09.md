## 判断したことと、その理由

| 判断 | 理由 |
|---|---|
| 調べた結果は**検体状態欄と別欄**に積む | 検体状態欄＝装置と受付が勝手に言ってくること。調べた結果＝自分で確かめたこと。混ぜると「装置が言った」のか「自分が見た」のか区別がつかなくなる |
| 正常検体の目視も**空振りにしない**（淡黄色／凝血なし／量十分） | `real`（採血に問題なし）は消去法で選ぶもの。その根拠を画面に出す操作が目視（investigate.md §1） |
| 電話は**調べた結果欄に短い一行、院内メッセージに看護師の言葉**の二本立て | 欄はLISの記録らしく詰めたい。台詞は台詞として読ませたい。両方を一か所に入れると、どちらも中途半端になる |
| `actions.forbid` は「**その行動をした人を弾く**」向き | 前スレの `comment` で一度間違えた向き。「していない人を拾う枝」は `must` を書かない枝で受ける。コメントとテストの両方に残した |
| 「1症例1回」＝**済んだ行動の再実行だけを潰す** | 最初は「再採血検体では目視以外を出さない」と実装したが、一本目で電話していない人が二本目で電話できないのはおかしい。§2 と §12 の文がどちらにも読めたので、文ごと直した |
| 「点滴側採血」を**希釈の別名から独立**させた | 希釈＝値がどう動くか、点滴側採血＝何をしたか。調べた結果から引きたいのは後者。同じ語を二重に持たない |

## 決まったこと（追加分）

- 症例に `investigate` / `actions` / `ask` を書かなければ、調べるも聞くも既定で動く。既存の枝はそのまま
- 調べた結果は検体状態欄に追記しない。何も調べていないときは欄ごと出さない
- 電話で返るのは検体側・採血側の事実と、横の連絡として当然の患者の様子まで。病名・身体所見・診断の示唆は返さない
- 塗抹は「見えた形」まで。芽球・異型リンパのような病名に繋がる読みは返さない
- 「聞く」は上のバー右端に固定。押す前に「1症例1回。聞くと評価は許容どまりになります」と言っておく（隠して減点しない）
- 指さしは画面の外にある的だけ寄せる。上のバーの中の的は寄せない（バーごと見えている）
- 上のバーはスマホ縦で一段（48px以内）。引っ込めるのは病院名・副題・指導役の名前・報告の内訳の4つで、
  どれも他の場所で読める。割り込み中はさらに集計と題字を落とす
- 色ルールは変えていない。行動ボタンの押せる・押せないは**濃さと添える一言**（「済」「血算の依頼なし」）で見せる

## 残していること

**1. 症例7-b「取り違え」**（roadmap §6 の 3-c）
`idcheck` の不一致が本領を出す症例。器（`investigate.idcheck.match: false`）は入っていて、テストもある。
骨子は investigate.md §11：病棟からのCBC＋生化学、前回値と全体に合わない、検体状態は空、目視も正常、
`delta` だけ選ぶと ok どまり、best は `mismatch` ＋ `actions.must: ["idcheck"]` ＋再採血。
**これを一本手書きしてから §6-4（判定ルールの言語化）に進む。**手書きの症例からルールを抽出する順番は変えない。

**2. 上級の時間コスト**（roadmap 進め方 8・investigate.md §7）
目視1分／ID照合1分／電話3分（ERは折り返しで5分）／塗抹10分。新人モードは無料のまま。
辞典と同じ「読むか読まないか」ではなく「今やるか、後でやるか」の設計。調べることが常に損にならない線は守る。

**3. 「聞く」の既定を逆引き辞典に差し替える**（roadmap 4章）
いまは索引の「見る順番」の五行を指導役の言い方で出している。逆引き辞典ができたら、
マーク済み or フラグ最上位の項目の逆引き一項目に差し替える。生成症例に台詞を書かない方針はそのまま。

**4. PLiCy のサムネイル**（未着手・仕様未定）
出すときに要る。絵柄の方針（characters.md）に合わせて、低彩度・細い線・写実にしない。
検査値の画面をそのまま出すのか、立ち絵を入れるのか、題字だけにするのかは未定。
**サイズと枚数の規定を PLiCy 側で確認してから決める。** 1ファイル結合（roadmap 9）と同じタイミングで片付ける。
